# Safety and Privacy Policy

## 1. 서비스 성격

MOA는 의료기기가 아니다. 음성 기록과 변화 흐름을 참고하는 웰니스 서비스다. 모든 화면, 응답, 리포트는 이 전제를 지켜야 한다.

## 2. 금지 표현

다음 표현은 UI, 챗봇 응답, 리포트, 코드 주석, mock 문구에 쓰지 않는다.

- 진단
- 처방
- 치료
- 확진
- 질환 단정
- 병명 단정
- 위험 판정
- 의학적 수치 판정

대체 표현:

- 감지
- 변화
- 참고
- 패턴
- 흐름
- 기록
- 살펴보기
- 쉬어가기

## 3. 색상 정책

- 빨간색 경고 UI는 사용하지 않는다.
- 주의나 경고에 가까운 상태는 `#E8943A`를 사용한다.
- 정상/안정 상태는 그린 계열을 사용할 수 있다.
- 색상만으로 의미를 전달하지 않는다.

## 4. 고령자 화면 정책

- 최소 텍스트 크기 18pt를 기본으로 한다.
- 터치 영역은 최소 56px 이상으로 한다.
- 핵심 행동은 한 화면에 1~2개만 둔다.
- 점수, 퍼센트, 임상 수치를 직접 표시하지 않는다.
- 날씨형 메타포를 우선 사용한다.

## 5. 보호자 화면 정책

- 추이 그래프와 요약 카드를 사용할 수 있다.
- 그래프는 참고용임을 명시한다.
- 보호자에게 의료적 결론을 제시하지 않는다.
- 원문 발화 노출은 기본 금지다. 제품 정책과 동의 절차가 확정되기 전까지 요약 중심으로 표시한다.

## 6. 음성/개인정보 정책

- 임시 음성 파일은 분석 또는 전송 후 즉시 삭제한다.
- 음성 파일을 localStorage, IndexedDB 등에 보관하지 않는다.
- 서버 저장이 필요해지면 보관 기간, 삭제 정책, 동의 흐름을 문서화한 뒤 구현한다.
- 로그에 다음 정보를 남기지 않는다.
  - 발화 원문
  - 음성 파일 URI
  - 사용자 이름과 식별자 조합
  - 가족 연결 정보
  - OpenAI API 응답 원문 전체
