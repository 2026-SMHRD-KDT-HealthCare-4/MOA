ML 엔드포인트

엔드포인트입력설명
POST /predict/parkinsonWAV 1개 (모음 발성)파킨슨 위험도 score/level
POST /predict/dementiaWAV 1~3개 (CTD/PFT/SFT)치매 위험도 (과제별 가중 앙상블)
POST /predict/diabetesWAV + age/bmi/gender당뇨 위험도 (성별 분리 모델)
POST /predict/diabetes/from_embeddingBYOL-S 임베딩 배열 2048차원임베딩 직접 입력 호환용
POST /predict/all여러 WAV통합 스크리닝 (한 번에)
ZDR (Zero Data Retention) 업로드된 WAV는 tempfile로만 처리하고, 추론 완료 즉시 os.remove()로 삭제. 어떤 테이블에도 음성 원본을 저장하지 않는다.
