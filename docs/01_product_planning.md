# Product Planning

## 1. 제품 정의

MOA는 고령층이 매일 짧은 음성 기록을 남기고, 보호자가 그 변화 흐름을 확인하는 웰니스 앱이다. 핵심 가치는 "매일 말하기 쉬운 기록"과 "보호자가 부담 없이 확인하는 변화 흐름"이다.

## 2. 사용자

### 고령자 사용자

- 직접 앱을 열어 오늘의 음성 기록을 남긴다.
- 챗봇과 간단히 대화할 수 있다.
- 기록 히스토리를 날씨형 메타포로 확인한다.
- 복잡한 수치나 의학적 표현보다 큰 글자, 큰 버튼, 단순한 흐름이 중요하다.

### 보호자 사용자

- 연결된 고령자의 최근 기록 여부와 변화 흐름을 확인한다.
- 추이 리포트와 요약 카드를 본다.
- 의료 판단이 아니라 안부 확인과 생활 패턴 참고에 초점을 둔다.

## 4. Out of Scope

다음 항목은 명시적 범위 변경 없이 구현하지 않는다.

- 실제 의료 수치 표시
- 진단, 처방, 치료 안내
- 보호자와 고령자의 실시간 음성 통화
- SNS 공유
- 다국어 지원
- 다크모드
- 백그라운드 상시 호출어 감지
- 외부 의료기기 연동 API

## 5. UX 원칙

- 고령자 화면은 한 화면에 핵심 행동 1개 또는 2개만 둔다.
- 아이콘만으로 의미를 전달하지 않고, 텍스트와 함께 제공한다.
- 수치 대신 날씨형 메타포를 사용한다.
- 보호자 화면은 요약, 비교, 추이 확인에 집중한다.
- 불안감을 키우는 경고 표현보다 "변화가 보여요", "조금 쉬어가요"처럼 부드러운 문구를 사용한다.
