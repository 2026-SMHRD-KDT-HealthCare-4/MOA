# Guardian App Feature Spec

## 1. 목적

보호자 앱은 연결된 고령자의 기록 여부와 변화 흐름을 부담 없이 확인하도록 돕는다.

## 2. 주요 화면

| 화면 | 파일 | 현재 상태 |
| --- | --- | --- |
| 대시보드 | `frontend/src/pages/DashboardPage.tsx` | mock 구현 |
| 가족 연결 | `frontend/src/pages/FamilyPage.tsx` | mock 구현 |
| 리포트 | `frontend/src/pages/ReportPage.tsx` | mock 구현 |
| 설정 | `frontend/src/pages/SettingsPage.tsx` | 부분 구현 |

## 3. 대시보드

- 연결된 고령자의 최근 기록 시각을 보여준다.
- 오늘의 상태를 날씨형 메타포로 보여준다.
- 최근 7일 흐름을 요약한다.
- 리포트 화면으로 이동할 수 있다.

## 4. 가족 연결

- 연결된 고령자 목록을 보여준다.
- 이름, 관계, 나이, 오늘 상태, 연속 기록일, 마지막 기록 시각을 보여준다.
- 실제 초대/연결 API는 아직 없다.

## 5. 리포트

- 최근 7일 변화 흐름을 차트로 표시한다.
- 보호자 화면에서는 내부 점수 기반 차트를 사용할 수 있다.
- 그래프는 참고용이며 의료적 판단 근거가 아님을 명시한다.
- 경고 색상은 빨간색이 아니라 `#E8943A`를 사용한다.

## 6. 금지 사항

- 보호자에게 "질병이 의심됩니다"처럼 단정하지 않는다.
- 특정 치료나 병원 방문을 지시하지 않는다.
- 고령자의 원문 발화 전체를 기본 노출하지 않는다. 필요한 경우 별도 정책과 동의가 필요하다.

## 7. 변경 기록

- 2026-06-15: 보호자 앱 기능 상세 문서 신설.
