# Elder App Feature Spec

## 1. 목적

고령자 앱은 매일 쉽게 음성 기록을 남기고, Moa 캐릭터와 가볍게 상호작용하는 경험을 제공한다.

## 2. 주요 화면

| 화면 | 파일 | 현재 상태 |
| --- | --- | --- |
| 홈 | `frontend/src/pages/HomePage.tsx` | 구현 |
| 녹음 | `frontend/src/pages/RecordPage.tsx` | 구현, STT mock/API 준비 |
| 완료 | `frontend/src/pages/DonePage.tsx` | 구현 |
| 히스토리 | `frontend/src/pages/HistoryPage.tsx` | mock 구현 |
| 설정 | `frontend/src/pages/SettingsPage.tsx` | 부분 구현 |
| 대화 | `frontend/src/pages/ChatPage.tsx` | mock/API 준비 |

## 3. 홈

- 따뜻한 크림/아이보리 그라데이션 배경을 사용한다.
- 날짜와 안부 인사를 상단에 크게 보여준다.
- 큰 흰색 말풍선으로 "오늘도 목소리 들려주세요" 메시지를 보여준다.
- Moa 캐릭터를 화면 중앙에 크게 보여준다.
- 큰 코랄색 녹음 버튼으로 기록 화면에 진입한다.
- 원형 초록 버튼으로 Moa와 대화하기 화면에 진입한다.
- 버튼은 아이콘과 텍스트를 함께 제공한다.

## 4. 녹음

- 마이크 권한을 요청한다.
- 녹음 중 호출어 감지를 비활성화한다.
- 녹음 종료 후 STT 처리를 시도한다.
- API 키가 없으면 mock transcript를 사용한다.
- 처리 완료 후 임시 음성 파일을 삭제한다.
- 완료 상태에서는 다시 녹음 또는 저장을 선택할 수 있다.

## 5. 히스토리

- 월간 캘린더를 보여준다.
- 기록이 있는 날은 날씨형 메타포로 표시한다.
- 고령자 화면에는 점수나 퍼센트를 표시하지 않는다.

## 6. 설정

- 알림 권한을 요청한다.
- 현재 역할과 버전을 보여준다.
- 로그아웃을 제공한다.

## 7. 금지 사항

- 고령자 화면에 "위험", "진단", "질환", "우울증" 같은 단정적 표현을 표시하지 않는다.
- 점수, 퍼센트, 임상 수치를 직접 표시하지 않는다.
- 한 화면에 복잡한 선택지를 많이 두지 않는다.
